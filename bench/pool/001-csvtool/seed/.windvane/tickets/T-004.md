# T-004: Sum a column by group
Depends on: T-003.
Touches: csvtool.py, tests/test_by.py.

## Goal
A user with a month of spending wants the total per category, not one total. That is the spreadsheet's pivot table,
and it should be one command that prints a CSV they can keep.

## Scope
`sum` takes `--by <column>`: instead of one number it prints one total per distinct value of that column, as CSV.
It works with `--where`, which picks the rows before they are grouped.

## Done when
- `python3 csvtool.py sum data.csv amount --by category` prints the header `category,amount`, then one row `<group>,<sum>` per distinct `category`, in the order each first appears in the file.
- each group's sum is exact and keeps its decimals as T-001's sums do (`0.10` and `0.20` in one group make `0.30`).
- group values holding commas or quotes come out as valid CSV, so reading the output back gives the group values as typed.
- with `--where`, only matching rows are grouped; a group with no matching row isn't printed.
- a `--by` column the header doesn't have prints `error: no column: <column>` to stderr and exits 1.
- tests in `tests/test_by.py` cover each point.
