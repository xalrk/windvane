# T-003: Sum only the rows that match
Depends on: T-002.
Touches: csvtool.py, tests/test_where.py.

## Goal
"How much did I spend on food over 10?" takes a filter and a sum today, piped together. One command should answer
it.

## Scope
`sum` takes `--where <condition>`, the same conditions as `filter`, and may take it more than once: a row counts only
if it matches every condition. Cells of rows that don't match are never looked at, so a non-number in a skipped row is
no error.

## Done when
- `python3 csvtool.py sum data.csv amount --where category=food` prints the sum of `amount` over the rows whose `category` is `food`.
- two `--where` conditions sum only the rows matching both; with no row matching, the sum is `0`.
- a cell that isn't a number in a row the conditions skip is no error; one in a row they keep prints the `error: line <n>: not a number: <cell>` of T-001.
- a bad condition prints `error: bad condition: <condition>` and exits 2; a condition on a column the header doesn't have prints `error: no column: <column>` and exits 1.
- tests in `tests/test_where.py` cover each point.
