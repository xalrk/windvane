# T-001: Sum a column
Depends on: nothing.
Touches: csvtool.py, tests/test_sum.py.

## Goal
csvtool can't do anything yet. The question a user asks most of an exported spreadsheet is "what does this column
add up to?", and the answer has to be exact: money in a CSV must not come back as `0.30000000000000004`.

## Scope
`python3 csvtool.py sum <file> <column>`, the column named by the header row. A number is an optional `-`, digits,
and optionally a `.` and more digits (`12`, `-3.5`, `0.10`); spaces around a cell are ignored, and blank cells are
skipped. The file is read as UTF-8, with or without a byte-order mark (spreadsheets often write one).

## Done when
- `python3 csvtool.py sum data.csv amount` prints the column's exact sum and nothing else: `0.10` and `0.20` make `0.30`, `12.5` and `3.25` make `15.75`.
- the sum keeps as many decimals as the most precise cell: `1.10` and `2` make `3.10`; a column of whole numbers sums to a whole number (`7`); a file with a header and no rows sums to `0`.
- blank cells are skipped, and a file saved with a byte-order mark works the same as one without, its first column included.
- a column the header doesn't have prints `error: no column: <column>` to stderr and exits 1.
- a cell that isn't a number prints `error: line <n>: not a number: <cell>` to stderr and exits 1, `<n>` being the file's line number (the header is line 1).
- a file that can't be read prints `error: cannot read <file>` to stderr and exits 1.
- tests in `tests/test_sum.py` cover each point.
