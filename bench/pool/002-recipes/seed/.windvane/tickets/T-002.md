# T-002: Scale a recipe to other servings
Depends on: T-001.
Touches: recipes.py, tests/test_scale.py.

## Goal
A recipe for four is no help when six are coming. Working each quantity out by hand is what this program is for.

## Scope
`python3 recipes.py scale <file>` takes either `--serves N` (the servings wanted) or `--by F` (a factor) and prints
the recipe as `show` does, every quantity scaled. Quantities are worked out exactly and rounded only when printed.

## Done when
- `scale pancakes.txt --serves 6` on a recipe for 4 prints `serves 6` and every quantity times 6/4 (`200 g flour` becomes `300 g flour`, `2 eggs` becomes `3 eggs`).
- `scale pancakes.txt --by 2` doubles every quantity and the serves line; `--by` also takes a decimal or a fraction (`0.5`, `1/2`), and the serves line is printed like a quantity (a recipe for 3 `--by 0.5` prints `serves 1.5`).
- a recipe for 3 with `100 g butter`, scaled `--serves 1`, prints `- 33.33 g butter`; one with `0.1 l stock` scaled `--by 3` prints `- 0.3 l stock`.
- giving both `--serves` and `--by`, or neither, prints a usage line to stderr and exits 2.
- a `--serves` that isn't a whole number above zero prints `error: bad serves: <value>`, and a `--by` that isn't a number above zero prints `error: bad factor: <value>`, each to stderr with exit 2.
- a missing or broken recipe file gives the same error and exit code as `show`.
- tests in `tests/test_scale.py` cover each point.
