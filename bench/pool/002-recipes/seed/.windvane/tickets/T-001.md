# T-001: Read a recipe file and show it
Depends on: nothing.
Touches: recipes.py, tests/test_show.py.

## Goal
The program can't read a recipe yet. Every later command (scaling, the shopping list) stands on reading the file
`CLAUDE.md` describes and pointing at the line a mistake is on.

## Scope
`python3 recipes.py show <file>` reads one recipe and prints it back in one tidy form. A quantity is a whole number
(`2`), a decimal (`1.5`), a fraction (`1/2`) or a whole number and a fraction (`1 1/2`). The units are `g`, `kg`,
`ml`, `l`, `tsp`, `tbsp` and `cup`; a word after the quantity that isn't one of them is the start of the name
(`2 eggs`, `3 large eggs`). Scaling is T-002.

## Done when
- `python3 recipes.py show pancakes.txt` prints the title (without the `# `), then `serves <N>`, then one line per ingredient in the file's order, `- <quantity> <unit> <name>`, or `- <quantity> <name>` when it has no unit.
- each quantity is printed as a number with at most two decimals and no trailing zeros: `1/2 kg` shows as `0.5 kg`, `1 1/2 kg` as `1.5 kg`, `0.250 l` as `0.25 l`, `200 g` as `200 g`.
- a file that doesn't exist prints `error: no such recipe: <file>` to stderr and exits 1.
- an ingredient line with no quantity at its start, a quantity of zero or less, or no name (`salt to taste`, `0 g salt`, `200 g`) prints `error: <file>:<line>: bad ingredient: <the line>` to stderr and exits 1, where `<line>` counts every line from 1, blank ones too.
- a first line that isn't `# <title>` prints `error: <file>:1: no title`, and a second non-blank line that isn't `serves <N>` with N a whole number above zero prints `error: <file>:<line>: no serves line`, each to stderr with exit 1.
- tests in `tests/test_show.py` cover each point.
