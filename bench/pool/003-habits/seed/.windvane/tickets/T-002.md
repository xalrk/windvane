# T-002: Show each habit's current and best streak
Depends on: T-001.
Touches: habits.py, tests/test_streak.py.

## Goal
A log of days done doesn't say what a user wants to know at the end of the day: how many days in a row they have
kept it up, and whether that beats their best.

## Scope
`python3 habits.py streak [<name>]`, read from `habits.txt`. A streak is a run of days done with no day missed
between them, across month and year ends and leap days alike.

## Done when
- `streak` prints one line per habit in the order they were added, `<name>: <N> days, best <M>` (`1 day` for one, `0 days` for none), and nothing else; with no habits, or no `habits.txt`, it prints `no habits yet`.
- the current streak is the run of days done that ends today, or that ends yesterday when today isn't done yet (the day isn't over); it is 0 when neither today nor yesterday is done.
- the best streak is the longest run of days done ever, the current one included: days done on `2024-02-28`, `2024-02-29` and `2024-03-01` are a run of 3, and so are `2023-12-30`, `2023-12-31` and `2024-01-01`.
- `streak read` prints only that habit's line; a habit not in the file prints `error: no such habit: <name>` and exits 1.
- a bad line in `habits.txt` gives the same error and exit code as in T-001.
- tests in `tests/test_streak.py` cover each point.
