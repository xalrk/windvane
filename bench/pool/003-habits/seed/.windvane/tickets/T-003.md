# T-003: Show the last seven days as a grid
Depends on: T-002.
Touches: habits.py, tests/test_week.py.

## Goal
A streak count hides the gaps. A user looking back on their week wants every habit's days side by side, at a glance.

## Scope
`python3 habits.py week [--ending <date>]`: the seven days ending today, or ending the date given, for every habit.

## Done when
- `week` prints `<first day> to <today>` (dates as `YYYY-MM-DD`, the first day six days before today), then one line per habit in the order they were added: its name padded with spaces to the length of the longest name, a space, seven marks for the seven days oldest first (`#` done, `.` not), a space and `<N>/7`, N the days done of the seven, and nothing else. For example:
  ```
  2026-10-21 to 2026-10-27
  read    ##.#..# 4/7
  stretch .....## 2/7
  ```
- `week --ending 2026-03-01` shows the seven days ending that day, across a month's end like any other week; a `--ending` that isn't a real date prints `error: bad date: <value>` and exits 2, and one after today prints `error: date in the future: <date>` and exits 1.
- with no habits, or no `habits.txt`, `week` prints `no habits yet`; a bad line in `habits.txt` gives the same error and exit code as in T-001.
- tests in `tests/test_week.py` cover each point.
