# T-001: Add habits and mark days done
Depends on: nothing.
Touches: habits.py, tests/test_track.py.

## Goal
The program can't keep a habit yet. Every later command (streaks, the week grid) stands on adding habits, marking the
days they were done in `habits.txt` as `CLAUDE.md` describes it, and pointing at the line a hand edit broke.

## Scope
`python3 habits.py add <name>`, `done <name> [--on <date>]` and `list`. A habit's name is a lowercase letter
followed by lowercase letters, digits or `-` (`read`, `no-sugar`, `run5k`). A date is written `YYYY-MM-DD`. Streaks
are T-002.

## Done when
- `add read` adds the line `habit read` to `habits.txt` (making the file when there is none) and prints `added read`; a name that isn't a good habit name (`Read`, `5k`, `no sugar`) prints `error: bad habit name: <name>` and exits 2, and a habit already in the file prints `error: habit exists: <name>` and exits 1, the file unchanged.
- `done read` marks today done and prints `read: done on <today>`; `done read --on 2026-10-01` marks that day instead; a day already done prints `read: already done on <date>`, exits 0 and adds nothing to the file.
- `done` with a habit not in the file prints `error: no such habit: <name>` and exits 1; a `--on` that isn't a real date in `YYYY-MM-DD` form (`2026-13-01`, `2026-02-30`, `yesterday`) prints `error: bad date: <value>` and exits 2; a date after today prints `error: date in the future: <date>` and exits 1. None of them changes the file.
- `list` prints one line per habit in the order they were added, `- <name>: <N> days` with N the number of different days it was done (`1 day` for one, `0 days` for none); with no habits, or no `habits.txt`, it prints `no habits yet`.
- a line of `habits.txt` that is none of a blank line, a `#` comment, `habit <name>` with a good name not already declared above it, or `<date> <name>` with a real date and a habit the file declares, makes every command print `error: habits.txt:<line>: bad line` and exit 1 without writing anything, where `<line>` counts every line from 1, blank ones too. The same day written twice by hand counts once.
- tests in `tests/test_track.py` cover each point.
