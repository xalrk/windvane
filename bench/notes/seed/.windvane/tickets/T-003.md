# T-003: Write and read notes on the page
Depends on: T-002.
Touches: app.py, tests/test_page.py.

## Goal
The page at `/` shows only a heading. A user should read and write notes there, with no JavaScript needed.

## Scope
The page lists the notes and has a plain HTML form; the form posts to `/notes`, which adds the note and sends the
browser back to `/`.

## Done when
- `GET /` shows every note's text in its own `<li>`, oldest first, with HTML in a note escaped (`<b>` shows as `&lt;b&gt;`).
- the page has a `<form method="post" action="/notes">` with a text field named `text`.
- a form post to `/notes` (`text=...`, form-encoded) adds the note and answers 303 with `Location: /`; an empty one adds nothing and still answers 303.
- tests in `tests/test_page.py` cover each point.
