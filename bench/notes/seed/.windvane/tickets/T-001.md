# T-001: Add and list notes through the JSON API
Depends on: nothing.
Touches: app.py, tests/test_api.py.

## Goal
The server can't hold a note yet. The JSON API is what the page and any script will build on.

## Scope
`POST /api/notes` with a JSON body `{"text": "..."}` adds a note; `GET /api/notes` lists them. Ids are 1, 2, 3, ...
in the order notes are added. Keeping them across a restart is T-002.

## Done when
- `POST /api/notes` with `{"text": "buy milk"}` answers 201 with `{"id": 1, "text": "buy milk"}`; the next note gets id 2.
- `GET /api/notes` answers 200 with a JSON list of every note, oldest first, each `{"id": <id>, "text": <text>}`.
- a note whose `text` is missing, not a string, or only spaces answers 400 with `{"error": <message>}` and adds nothing.
- tests in `tests/test_api.py` cover each point.
