# T-004: Search notes, and answer bad requests in JSON
Depends on: T-003.
Touches: app.py, tests/test_search.py.

## Goal
With many notes, finding one means scrolling; and a script that sends something wrong gets an HTML error page or a
dropped connection instead of an answer it can read.

## Scope
A `q` parameter on the list; every API error answered as JSON.

## Done when
- `GET /api/notes?q=<words>` lists only the notes whose text contains `<words>`, ignoring case.
- a body that isn't JSON, or isn't a JSON object, on `POST /api/notes` answers 400 with `{"error": <message>}`.
- any other path under `/api/` answers 404 with `{"error": <message>}`, for GET, POST and DELETE alike.
- tests in `tests/test_search.py` cover each point.
