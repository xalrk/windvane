# T-002: Keep notes in the data file, and delete them
Depends on: T-001.
Touches: app.py, tests/test_store.py.

## Goal
Notes vanish when the server stops, and a wrong note can't be taken back.

## Scope
Notes are kept in the `--data` file as JSON, written whole each time (a temporary file renamed over it), and read
at start. `DELETE /api/notes/<id>` removes one.

## Done when
- notes are kept in the `--data` file: after the server is stopped and started again on the same file, `GET /api/notes` lists the same notes and the next note gets the next id.
- `DELETE /api/notes/<id>` answers 204 and the note is gone from the list, also after a restart.
- `DELETE` of an id there is no note for answers 404 with `{"error": <message>}`.
- tests in `tests/test_store.py` cover each point.
