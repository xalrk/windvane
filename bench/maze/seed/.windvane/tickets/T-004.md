# T-004: Save and load a game
Depends on: T-003.
Touches: game.py, tests/test_save.py.

## Goal
A long maze has to be played in one go, and a crash loses the game.

## Scope
`save <file>` and a `--load <file>` option. A save is written whole or not at all.

## Done when
- `save <file>` writes the game to `<file>` and prints `Saved.`; `python3 game.py <map> --load <file>` goes on from there: the same square, keys and moves, and the keys taken and doors opened stay so.
- a save file that is missing or isn't one this program wrote prints `error: can't load <file>` to stderr and exits 2, before reading any input.
- a save to a folder that doesn't exist prints `Can't save there.` and the game goes on.
- tests in `tests/test_save.py` cover each point.
