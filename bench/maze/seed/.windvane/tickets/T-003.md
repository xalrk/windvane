# T-003: Escape, and count the moves
Depends on: T-002.
Touches: game.py, tests/test_escape.py.

## Goal
There's no way to win, and no score to beat.

## Scope
The exit ends the game; moves are counted.

## Done when
- reaching the exit `E` prints, after the position line, `You escape in <n> moves!` where n counts the moves that changed square, and the game ends with exit code 0, reading no more input.
- `moves` prints `Moves: <n>`.
- when the input ends before the exit is reached, the game prints `You are still in the maze.` and exits 1.
- tests in `tests/test_escape.py` cover each point.
