# T-001: Add entries to the ledger
Depends on: nothing.
Touches: ledger.py, tests/test_add.py.

## Goal
The ledger can't hold anything yet. Adding an entry is the first thing a user does: an amount and a note, kept in
the ledger file so every later command sees it.

## Scope
`python3 ledger.py add <amount> <note...>`: the amount is a number with at most two decimals, and may be negative
(a refund); the note is the rest of the words. Entries get ids 1, 2, 3, ... in the order they're added.

## Done when
- `python3 ledger.py add 12.50 coffee beans` prints `added #1`, and the next add prints `added #2`.
- the file `--file` names (default `ledger.json` in the current directory) is created and holds every entry as JSON.
- a negative amount is an entry too: `add -3.20 refund` prints its `added #<id>` line.
- an amount that isn't a number with at most two decimals (`12.555`, `abc`) prints `error: bad amount: <amount>` to stderr, exits 2 and leaves the file unchanged.
- tests in `tests/test_add.py` cover each point.
