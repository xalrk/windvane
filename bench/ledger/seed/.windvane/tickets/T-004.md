# T-004: Refuse a broken ledger file
Depends on: T-003.
Touches: ledger.py, tests/test_broken.py.

## Goal
A ledger file someone edited by hand, or one cut short by a crash, must never be overwritten or shown as if it were
fine: it is the user's only copy of their entries.

## Scope
Every command checks the file it reads. Writes go to a temporary file first, renamed over the ledger file when
complete, so a crash mid-write leaves the old file whole.

## Done when
- a file that isn't a ledger written by this program makes every command print `error: <file> is not a ledger file` to stderr and exit 1, leaving the file byte for byte as it was.
- `add` with a `--file` in a folder that doesn't exist prints one line starting `error: ` and exits 1, with no traceback.
- a leftover `<file>.tmp` from a crashed write is ignored: `list` shows the entries of `<file>`, and the next `add` works.
- tests in `tests/test_broken.py` cover each point.
