# T-003: Remove an entry
Depends on: T-002.
Touches: ledger.py, tests/test_remove.py.

## Goal
A typo stays in the ledger for good. A user must be able to take an entry back out by its id.

## Scope
`python3 ledger.py remove <id>`. Ids stay unique for the life of the file.

## Done when
- `python3 ledger.py remove 2` prints `removed #2`, and `list` no longer shows it.
- an id that isn't in the ledger prints `error: no entry #9` (for 9) to stderr and exits 1.
- ids are never reused: with entries #1 and #2, after `remove 2` the next add prints `added #3`.
- tests in `tests/test_remove.py` cover each point.
