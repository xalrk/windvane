# T-002: List the entries and the balance
Depends on: T-001.
Touches: ledger.py, tests/test_list.py.

## Goal
Entries go in but can't be seen. A user needs to read them back and know where they stand.

## Scope
Two commands, `list` and `balance`. Amounts are shown with two decimals and summed exactly (no float rounding).

## Done when
- `python3 ledger.py list` prints one line per entry, oldest first: `#<id> <amount> <note>`, e.g. `#1 12.50 coffee beans`.
- `python3 ledger.py balance` prints `balance: <sum>` with two decimals, summed exactly: `0.10` and `0.20` make `balance: 0.30`.
- with no ledger file yet, `list` prints nothing and `balance` prints `balance: 0.00`, both exiting 0.
- tests in `tests/test_list.py` cover each point.
